## Commands

1. **/leaderboard** › Opens the leaderboard GUI
2. **/topkills** › Opens the kills leaderboard GUI
3. **/topdeaths** › Opens the deaths leaderboard GUI
4. **/playtimetop** › Opens the playtime leaderboard GUI
5. **/hologram create \<preset\> \[name\]** › Creates a new hologram at your location
6. **/hologram delete \<name\>** › Deletes a hologram
7. **/hologram teleport \<name\>** › Teleports to a hologram
8. **/hologram edit \<name\> movehere** › Moves hologram to your location
9. **/hologram edit \<name\> billboard \<type\>** › Sets billboard type
10. **/hologram edit \<name\> rotate \<yaw\>** › Rotates hologram horizontally
11. **/hologram edit \<name\> rotatepitch \<pitch\>** › Rotates hologram vertically
12. **/hologram edit \<name\> setline \<line\> \<text\>** › Sets a line's text
13. **/hologram edit \<name\> visibilitydistance \<distance\>** › Sets visibility distance
14. **/hologram edit \<name\> textshadow \<true|false\>** › Enables/disables text shadow
15. **/hologram edit \<name\> background \<transparent|default|color\> \<opacity\>** › Bg<br />- **(Background supports all color types like RED, BLUE, &#RRGGBB, #RRGGBB)**<br />- The default opacity (max) is 1.
16. **/hologram edit \<name\> scale \<1-10\>** › Sets hologram scale
17. **/hologram edit \<name\> delete** › Deletes hologram via edit
18. **/hologram edit \<name\> removeline \<line\>** › Deletes hologram line
19. **/hologram edit \<name\> textalignment (center|left|right)** › Centers hologram text
20. **/hologram copy \<hologramname\> \<newhologramname\>** › Copies a hologram
