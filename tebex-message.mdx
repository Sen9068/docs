```yaml
  title: 'New purchase'
  description: ".\n> **Player:** {player}\n> **Package:** {package}\n> **Price:** {price}€"
  color: 51182

```

## Commands

1. **/tebexmessage (player) (package) (price)** › Sends a Tebex purchase notification
2. **/tebexmessage reload** › Reloads the TebexMessage configuration

You can add to (package) whatever package name you want and whatever (price) you want too.
