## Configuration

The default config.yml is very long but it contains all the items you can obtain in survival that you can sell. On line `1151` you can edit the price lore format.

## Commands

1. **/sell** › Opens the sell GUI
2. **/sell hand** › Sells the item in your hand
3. **/worth** › Opens the item worth GUI

## Permissions

| Permission | Description | Default |
| --- | --- | --- |
| `smp.sell.use` | Uses `/sell` and `/worth` | true |
